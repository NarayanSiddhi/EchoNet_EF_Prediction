EF prediction: what we built, results, and takeaways

Short summary of the pediatric ejection fraction (EF) models in ef_prediction/: architecture, validation numbers, and how we checked demographics and embeddings.

What the models do

  • Input: Echo video (32 frames, 128×128) plus an 11-number demographic vector (sex, age bin, BMI category).
  • Real model: One ResNet–LSTM stream on the real clip; demographics are encoded and concatenated with the video summary before the final layers that output EF.
  • Fused model: Same idea, but each frame uses a learned mix of real and synthetic video (gated fusion), then the same LSTM, demographics, and EF head.

Both models train mainly to minimize EF error, with an extra contrastive-style loss on a video-only side vector (not on the part that already includes demographics).

Results (validation)

EF errors are in percentage points (e.g. MAE ≈ mean |predicted EF − true EF|). Lower MAE / MSE / RMSE is better; higher R² is better (up to 1). Re-run evaluate_ef_real.py / evaluate_ef_fused.py after retraining to refresh checkpoint metrics.

How we studied demographics and plots

  1. Embeddings (t-SNE / UMAP)
    Early plots used a vector that does not include demographics (video-only). Coloring by sex/age/BMI looked mixed because that vector never saw those inputs.
    Use head_input in the viz scripts so the 2D plot matches what the EF head actually receives.

  2. Ablation
    Script ablate_demographic_effect.py: compare normal vs zeroed vs shuffled demographics. If scores barely change, the model is leaning mostly on video; if they change a lot, demographics matter for the prediction.

  3. Hypersphere (3D)
    Tool visualize_hypersphere.py: normalize features, PCA to 3D, plot on a unit sphere. EF-colored plots tend to show structure (the model organizes features around the task). Sex-colored plots often stay mixed in the first 3 directions—expected when the main signal is echo appearance, not a separate “sex axis.”

  4. FairHICON PDF
    That paper uses genomics and separate male/female/common pathways. We did not copy that architecture; we only borrow ideas (e.g. hierarchical contrastive on the video side). Do not expect the same 3D “regions” unless you redesign the network and losses that way.

Main conclusions

  • The pipeline predicts EF from video, with demographics fused in late; the fused variant beats the real model on overall MAE/MSE in the tables above (JSON and grouped summaries agree on direction).
  • Subgroup tables show error is not uniform (e.g. infants 0–1 y highest MAE; several age/BMI bins lower). That is descriptive reporting, not proof that demographics cause those gaps.
  • Embedding color is easy to misread: use head_input for “what the regressor sees,” and treat maps as illustrations, not proof of fairness or causality.
  • To argue whether demographics change the output, rely on ablation and subgroup errors, not only on t-SNE/UMAP/sphere pictures.
